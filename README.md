# 🎮 Python Logic Games

Welcome to my Python Logic Games repository! 👋

This repository contains small games I developed while learning and practicing Python programming. These projects help me strengthen my logical thinking, problem-solving skills, and understanding of Python fundamentals through hands-on practice.

# 🕹️ Games Included

## 1. Rock Paper Scissors ✊✋✌️

A classic Rock Paper Scissors game where the player competes against the computer.

### Concepts Practiced:

Conditional statements (if, elif, else)

User input and output

Random number generation

Basic game logic

## 2. Mystery Word 🔤

A word-guessing game where the player tries to guess a mystery word.

### Concepts Practiced:

Strings and variables

Loops

Conditional statements

User input and game logic

### 🛠️ Technologies Used

Programming Language: Python 3

Tools: Python-compatible code editor or terminal

Version Control: Git and GitHub

# 🚀 How to Run
### Step 1: Clone the Repository

Open your terminal and run:

git clone https://github.com/Alenjop-aj/python-logic-games.git

### Step 2: Navigate to the Project Folder

cd python-logic-games

### Step 3: Run a Game

Run Rock Paper Scissors:

python rock_paper_scissors.py

Run Mystery Word:

python mystery_word.py

### Note: Make sure the filenames in these commands match the actual Python files in this repository. Python 3 must be installed on your computer.
